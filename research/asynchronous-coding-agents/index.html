Governing Token Costs and User Control in Asynchronous Coding Agents

A design-science study of time-based token prices, scoped delegation and reviewable decisions in asynchronous coding work.

Journal
Australasian Journal of Information Systems
Author
Zishuo Yang

Research question

How can developers use a cheaper execution window while retaining control over decisions an agent makes in their absence?

Method

The study examines an archived prototype and two de-identified engineering traces, using 34 targeted offline regression checks, a queue replay and deterministic pricing scenarios. The prototype connects a planning brief and scoped delegation to a canvas of decisions and module versions.

Key findings

Targeted offline checks
34
De-identified engineering traces
2
Estimated reduction in one completed trace
16.5%
  • In one completed trace, halving execution rates reduced the two-phase cost estimate by 16.5%, with token usage and peak-priced planning held fixed.
  • The queue replay showed how a flexible high-priority task can consume the only affordable slot for a later task. An earlier placement can accommodate both at a higher forecast cost.

Limitations

Cost results are conditional estimates from archived usage and assumed prices. They do not measure provider bills, user outcomes or production scheduling performance.
